## 📌 Project Overview
[cite_start]The **Virtual Memory Management Simulator** is an interactive web-based tool designed to visualize how modern operating systems manage memory using paging, page tables, and page replacement algorithms[cite: 20, 21]. 

[cite_start]In real operating systems, memory management concepts like address translation and page faults happen in the background, making them difficult to visualize[cite: 22]. [cite_start]This project solves that problem by offering a step-by-step simulation of logical-to-physical address translation, page loading, and eviction strategies[cite: 23, 24].

[cite_start]**Target Audience:** Undergraduate OS students and candidates preparing for technical interviews[cite: 29].

---

## ✨ Key Features

* [cite_start]**Core Simulation Engine:** Handles paging operations, address translation, and page fault detection[cite: 37, 38, 40].
* **Page Replacement Algorithms:** Fully functional implementation of:
    * [cite_start]**FIFO** (First-In-First-Out) [cite: 76]
    * [cite_start]**LRU** (Least Recently Used) [cite: 78]
    * [cite_start]**Optimal** (Predictive replacement) [cite: 79]
* **Interactive Visualization:**
    * [cite_start]**Memory Frames:** Color-coded frames showing hits (green), faults (red), and victim frames (yellow)[cite: 134, 135].
    * [cite_start]**Live Page Table:** Updates dynamically to show Present bit, Frame number, Dirty bit, and Last Accessed time[cite: 138].
* [cite_start]**Real-Time Analytics:** Live charts tracking page faults and statistics for Hit Ratio, Miss Ratio, and Swap counts[cite: 142, 88].
* [cite_start]**Scenario Builder:** Generate random traces or use presets (Locality, Looping) to stress-test algorithms[cite: 154, 155].

## 📂 System Architecture

[cite_start]The project is modularized into three distinct layers[cite: 32]:

### 1. Module 1: Core Simulation Engine (Backend Logic)
Responsible for the math and OS logic behind the scenes.
* [cite_start]`memoryManager.js`: Handles page access, faults, and frame updates[cite: 47].
* [cite_start]`algorithms.js`: Contains the logic for FIFO, LRU, and Optimal[cite: 50].
* [cite_start]`pageTable.js`: Maintains page entries and status bits[cite: 49].

### 2. Module 2: UI Visualization Layer
Visualizes the state generated by the core engine.
* [cite_start]`MemoryView.jsx`: Renders physical memory frames and animations[cite: 108].
* [cite_start]`StatsPanel.jsx`: Displays real-time hit/miss ratios[cite: 113].
* [cite_start]`ChartView.jsx`: Renders the fault trend graph[cite: 116].

### 3. Module 3: Scenarios & Results
* [cite_start]`traceGenerator.js`: Creates random or pattern-based memory access traces[cite: 164].
* [cite_start]`results.js`: Allows exporting simulation stats to CSV for analysis[cite: 163].
