## 📌 Project Overview
The **Virtual Memory Management Simulator** is an interactive web-based tool designed to visualize how modern operating systems manage memory using paging, page tables, and page replacement algorithms

In real operating systems, memory management concepts like address translation and page faults happen in the background, making them difficult to visualize[cite: 22]. This project solves that problem by offering a step-by-step simulation of logical-to-physical address translation, page loading, and eviction strategies
[cite_start]**Target Audience:** Undergraduate OS students and candidates preparing for technical interviews[cite: 29].

---

## ✨ Key Features

***Core Simulation Engine:** Handles paging operations, address translation, and page fault detection.
* **Page Replacement Algorithms:** Fully functional implementation of:
    * **FIFO** (First-In-First-Out) 
    * ]**LRU** (Least Recently Used) 
    * **Optimal** (Predictive replacement) 
* **Interactive Visualization:**
    ***Memory Frames:** Color-coded frames showing hits (green), faults (red), and victim frames (yellow).
    * **Live Page Table:** Updates dynamically to show Present bit, Frame number, Dirty bit, and Last Accessed time.
* **Real-Time Analytics:** Live charts tracking page faults and statistics for Hit Ratio, Miss Ratio, and Swap counts.
* **Scenario Builder:** Generate random traces or use presets (Locality, Looping) to stress-test algorithms.

## 📂 System Architecture

[cite_start]The project is modularized into three distinct layers[cite: 32]:

### 1. Module 1: Core Simulation Engine (Backend Logic)
Responsible for the math and OS logic behind the scenes.
*`memoryManager.js`: Handles page access, faults, and frame updates.
* `algorithms.js`: Contains the logic for FIFO, LRU, and Optimal.
* `pageTable.js`: Maintains page entries and status bits.

### 2. Module 2: UI Visualization Layer
Visualizes the state generated by the core engine.
* `MemoryView.jsx`: Renders physical memory frames and animations.
* `StatsPanel.jsx`: Displays real-time hit/miss ratios.
* `ChartView.jsx`: Renders the fault trend graph.

### 3. Module 3: Scenarios & Results
* `traceGenerator.js`: Creates random or pattern-based memory access traces.
* `results.js`: Allows exporting simulation stats to CSV for analysis.
