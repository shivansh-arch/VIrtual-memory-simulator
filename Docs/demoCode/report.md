# Virtual Memory Management Simulator

## 1. Objective
To visualize paging, page faults, and page replacement algorithms
through an interactive web-based simulation tool.

## 2. Modules Overview
- Core Simulation Module – Handles memory logic (paging, faults)
- Visualization Module – Displays results with charts
- Documentation Module – Demonstrates code and explains behavior

## 3. Algorithm Overview
### a) Least Recently Used (LRU)
- Replaces the page that hasn’t been used for the longest time.

### b) Optimal Replacement
- Replaces the page that won’t be used for the longest period in the future.
